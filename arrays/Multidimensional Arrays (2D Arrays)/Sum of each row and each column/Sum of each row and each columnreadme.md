Sum of Each Row and Each Column in C
Description

This program calculates the sum of elements in each row and each column of a given matrix.
It uses two-dimensional arrays and nested loops to traverse the matrix and compute the required sums.

Objectives

To understand row-wise and column-wise matrix operations
To calculate the sum of each row in a matrix
To calculate the sum of each column in a matrix
To practice nested loops with 2D arrays

Concepts Covered
Two-dimensional arrays
Matrix traversal
Nested for loops
Arithmetic operations

Technologies Used
Programming Language: C
Compiler: Code::Blocks
Platform: Windows

Program Flow
Read number of rows and columns
Read elements of the matrix
Store elements in a 2D array
Calculate and display the sum of each row
Calculate and display the sum of each column

Sample Input
Enter number of rows and columns: 3 3

Enter elements of the matrix:
1 2 3
4 5 6
7 8 9

Sample Output

Sum of Row 1 = 6
Sum of Row 2 = 15
Sum of Row 3 = 24


Sum of Column 1 = 12
Sum of Column 2 = 15
Sum of Column 3 = 18

Learning Outcomes
Understood how to traverse a matrix row-wise and column-wise
Learned to perform calculations using 2D arrays
Improved understanding of nested loops
Gained confidence in solving matrix-based problems

Future Enhancements
Support for dynamic matrix size using malloc()

Conclusion
This program demonstrates a clear and systematic approach to finding the sum of each row and each column in a matrix using C language.
