README – Sparse Matrix Representation
Description
This program converts a given matrix into its sparse matrix representation.
Only non-zero elements are stored to save memory.

Objectives

To understand sparse matrix concept
To reduce memory usage
To store only non-zero elements


Concepts Covered
2D arrays
Sparse matrix
Conditional logic
Nested loops


Technologies Used
Language: C
Compiler: Code::Blocks
Platform: Windows

Program Flow
Read matrix size
Read matrix elements
Store non-zero elements
Display sparse matrix

Sample Input
3 3
1 0 0
0 5 0
0 0 9

Sample Output
Row Col Value 
3   3   3 
0   0   1
1   1   5
2   2   9

Learning Outcomes
Learned sparse matrix storage
Improved understanding of matrices
Efficient memory usage

Future Enhancements
Sparse matrix addition
Dynamic sparse matrix


Conclusion
This program efficiently represents a matrix in sparse format using C.
