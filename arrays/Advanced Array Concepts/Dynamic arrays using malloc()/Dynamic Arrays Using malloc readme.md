Dynamic Arrays Using malloc() in C
Description
This program demonstrates the use of dynamic memory allocation in C using the malloc() function.
It allows the user to create an array at runtime, store elements, and display them.

Objectives
To understand dynamic memory allocation in C
To create arrays at runtime using malloc()
To store and access elements using pointers
To practice memory management concepts

Concepts Covered
Dynamic memory allocation
Pointers
malloc() and free() functions
One-dimensional arrays

Technologies Used
Programming Language: C
Compiler: Code::Blocks
Platform: Windows

Program Flow
Read the number of elements
Allocate memory dynamically using malloc()
Read elements into the allocated memory
Display the array elements
Free the allocated memory

Sample Input
Enter number of elements: 5

Enter elements:
10 20 30 40 50

Sample Output
Array elements are:
10 20 30 40 50

Learning Outcomes
Understood dynamic memory allocation concepts
Learned how to use pointers with arrays
Gained experience with malloc() and free()
Improved memory handling skills

Future Enhancements
Use calloc() and realloc() functions
Implement dynamic resizing of arrays
Add error handling for memory allocation failure

Conclusion
This program provides a clear understanding of dynamic arrays using malloc() in C language.
