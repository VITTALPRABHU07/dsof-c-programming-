README – Diagonal & Anti-Diagonal Sum

Description
This program calculates the sum of diagonal and anti-diagonal elements of a square matrix.

Objectives
To understand diagonal elements
To perform matrix traversal

Concepts Covered
Square matrix
Looping
Index manipulation
Program Flow
Read matrix size
Read elements
Calculate diagonal sums

Sample Output

Sum of Diagonal = 15
Sum of Anti-Diagonal = 15

Learning Outcomes
Matrix indexing
Improved logic building

Conclusion
This program demonstrates matrix diagonal operations clearly.
