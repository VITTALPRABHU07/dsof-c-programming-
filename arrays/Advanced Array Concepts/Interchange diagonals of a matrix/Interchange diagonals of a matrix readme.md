Interchange diagonals of a matrix

Description
This program interchanges (swaps) the main diagonal and the anti-diagonal elements of a square matrix.
It uses two-dimensional arrays and index manipulation to perform diagonal swapping efficiently.

Objectives
To understand main and anti-diagonal elements of a matrix
To perform diagonal interchange operations
To practice matrix manipulation using 2D arrays
To apply swapping logic in matrices

Concepts Covered
Two-dimensional arrays
Square matrix
Diagonal and anti-diagonal elements
Nested for loops
Index manipulation

Technologies Used
Programming Language: C
Compiler: Code::Blocks
Platform: Windows

Program Flow
Read the size of the square matrix
Read elements of the matrix
Identify main diagonal and anti-diagonal elements
Swap the diagonal elements
Display the modified matrix

Sample Input
Enter matrix size: 3


Enter elements of the matrix:
1 2 3
4 5 6
7 8 9

Sample Output
Matrix after interchanging diagonals:
3 2 1
4 5 6
9 8 7

Learning Outcomes
Understood diagonal indexing in square matrices
Learned how to swap elements using temporary variables
Improved matrix manipulation skills
Strengthened logic-building using loops

Future Enhancements
Validate input to ensure square matrix
Perform diagonal interchange for larger matrices dynamically
Combine with other matrix operations

Conclusion
This program demonstrates a simple and effective method to interchange the diagonals of a square matrix using C language.
