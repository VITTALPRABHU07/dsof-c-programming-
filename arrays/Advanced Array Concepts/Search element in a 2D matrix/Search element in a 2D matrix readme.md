Search Element in a 2D Matrix in C
Description
This program searches for a given element in a two-dimensional matrix.
If the element is found, the program displays its row and column position; otherwise, it reports that the element is not present in the matrix.

Objectives
To understand searching techniques in a 2D matrix
To locate an element using row and column indices
To practice matrix traversal using nested loops
To improve logical thinking using conditional statements

Concepts Covered
Two-dimensional arrays
Matrix traversal
Linear search technique
Conditional statements
Nested for loops

Technologies Used
Programming Language: C
Compiler: Code::Blocks
Platform: Windows

Program Flow
Read number of rows and columns
Read elements of the matrix
Read the element to be searched
Traverse the matrix element by element
Display the position if the element is found
Display appropriate message if the element is not found

Sample Input
Enter number of rows and columns: 3 3

Enter elements of the matrix:
1 2 3
4 5 6
7 8 9

Enter element to search: 5

Sample Output
Element found at position (1, 1)

Learning Outcomes
Learned how to search elements in a matrix
Understood row-wise and column-wise indexing
Improved usage of nested loops and conditionals
Gained confidence in solving matrix-based problems

Future Enhancements
Implement binary search for sorted matrices
Count number of occurrences of the searched element
Improve efficiency using optimized search algorithms

Conclusion

This program demonstrates a straightforward approach to searching an element in a 2D matrix using C language.
