Description
This program demonstrates the implementation of jagged arrays using pointers in C.
A jagged array is a two-dimensional array in which each row can have a different number of columns, and memory is allocated dynamically for each row.

Objectives
To understand the concept of jagged arrays
To implement jagged arrays using pointers
To allocate memory dynamically for each row
To practice pointer and dynamic memory concepts

Concepts Covered
Pointers
Dynamic memory allocation
Jagged arrays
malloc() function
Nested loops

Technologies Used
Programming Language: C
Compiler: Code::Blocks
Platform: Windows

Program Flow
Declare an array of pointers
Allocate different memory sizes for each row using malloc()
Read elements into each row
Display the jagged array
(Optional) Free the allocated memory

Sample Input
Enter elements:
1 2
3 4 5
6 7 8 9

Sample Output
Jagged Array:
1 2
3 4 5
6 7 8 9

Learning Outcomes
Understood the structure of jagged arrays
Learned dynamic memory allocation for 2D data
Improved pointer handling skills
Gained confidence in working with non-uniform data structures

Future Enhancements
Accept dynamic row sizes from the user
Use realloc() for resizing rows
Implement jagged matrix operations

Conclusion
This program clearly demonstrates the creation and usage of jagged arrays using pointers in C language.
